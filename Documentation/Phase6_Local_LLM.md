**Status:** COMPLETE

## Overview

Phase 6 replaces `MockLLMProvider` with a real, fully offline-capable local LLM served by **Ollama** running on `localhost:11434`. All conversational responses from CYNEXIS are now generated by **llama3:8b** (Q4_0, 4.66 GB), a 8B parameter LLaMA 3 model running entirely on CPU.

The existing STT, TTS, VLM, Intent Engine, Safety Validator, Action Registry, Camera, and VoicePipeline systems are **completely unchanged**.

---

## Architecture

```
User Voice Input
       │
       ▼
 [Faster-Whisper STT]
       │
       ▼
 [Intent Engine] ─── match ──► [SafetyValidator] ──► [ActionRegistry] ──► Robot Hardware
       │
       │ no match (conversational)
       ▼
 [OllamaLLMProvider.stream()]
       │ token stream
       ▼
 [_sentence_chunker()]
       │ complete sentences
       ▼
 [Kokoro TTS.synthesize()]
       │ audio chunks
       ▼
 [playback_queue] ──► Speaker
```

**Safety guarantee:** The LLM path is only reached when the Intent Engine finds no hardware action match. The LLM cannot directly trigger any robot hardware.

## Configuration

### `.env` settings

```ini
LLM_PROVIDER=ollama          # "mock" | "ollama"
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=llama3:8b
OLLAMA_TEMPERATURE=0.7
OLLAMA_MAX_TOKENS=150
OLLAMA_TIMEOUT_S=30.0
OLLAMA_CONTEXT_WINDOW=8      # conversation turns retained
```

To revert to mock mode without code changes: set `LLM_PROVIDER=mock`.

## Performance Notes

- **Cold start:** First inference after server restart takes ~1.5s TTFT; subsequent calls drop to ~1.0s
- **Streaming:** TTS starts synthesizing the first sentence (~2.3s) while the LLM continues generating — the user hears audio before the response is complete
- **CPU-only:** Upgrading to a GPU would reduce TTFT to ~0.1–0.2s and throughput to ~60–100 tok/s
- **Qwen3:4b** can be added anytime via `ollama pull qwen3:4b` and setting `OLLAMA_MODEL=qwen3:4b` in `.env`

---

## Offline Operation

The Ollama server caches model weights locally at `~/.ollama/models/`. Once `llama3:8b` is pulled, **no internet connection is required** for inference. The Python client connects only to `localhost:11434`.

To verify: disable network adapter, run `python main.py --conversation-test` → CYNEXIS responds normally.

---

## Switching Models

To use a different model:

1. Pull with Ollama: `ollama pull qwen3:4b` (or any GGUF-compatible model)
2. Update `.env`: `OLLAMA_MODEL=qwen3:4b`
3. Restart CYNEXIS — no code changes needed

The `OllamaLLMProvider` automatically strips Qwen3's `<think>...</think>` reasoning blocks from responses.
